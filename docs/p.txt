 Recap & Engineering Guide: Speech Intent Decoding from Brain Signals

    What We've Done

    1. Data Acquisition

    - Downloaded Willett et al. (Nature 2023) speech neuroprosthesis dataset from
    Zenodo (mirror of Dryad, which has bot protection)
    - Source: https://zenodo.org/api/records/8047896/files/<filename>/content
    - Downloaded 3 archives:
      - diagnosticBlocks.tar.gz (799MB) — 20 sessions, 8-word classification
    (DO_NOTHING, bah, choice, day, kite, though, veto, were)
      - tuningTasks.tar.gz (898MB) — phonemes (40 classes), orofacial (34 classes),
    50-word set (51 classes)
      - competitionData.tar.gz (3.5GB) — sentence-level data

    2. Data Format (Willett Dataset)

    - NOT raw ECoG voltage — already preprocessed spike band power features
    - spikePow: T×256 matrix at 20ms bins (50Hz), spike band power per channel
    - tx1-tx4: threshold crossing counts at different thresholds (-3.5 to -6.5 ×
    RMS)
    - trialCues, cueList, goTrialEpochs, blockNum, trialState for trial structure
    - 256 intracortical microelectrode channels (4 arrays: Area 44 sup/inf, Area 6v
    sup/inf)

    3. Preprocessing Pipeline (preprocess.py)

    - Extract tar.gz → load .mat files via scipy.io.loadmat
    - Z-score spikePow and tx features per block (critical for combating
    nonstationarity)
    - Concatenate spikePow + tx1-tx4 → 256×5 = 1280 features per time bin
    - Segment trials: 10 bins pre-onset + 75 bins post-onset = 85 time steps per
    trial
    - For classical ML: time-bin into 100ms windows + temporal derivatives → flat
    feature vector (42,240 dims)
    - Save as .npz files in data/processed/

    4. Training Pipeline (train.py)

    - All computation on GPU (CUDA_VISIBLE_DEVICES=4,5,6,7)
    - GPU classifiers via PyTorch: Linear, MLP-256, MLP-512, DeepMLP — with AMP
    (mixed precision)
    - GPU PCA via torch.linalg.svd
    - DL models: EEGNet, TCN, GRU, Transformer — DataParallel across 4× H100 GPUs
    with AMP
    - Cross-validation: Leave-One-Session-Out (20 folds for diagnostic blocks)
    - Data augmentation: Gaussian noise, time shift, channel dropout

    Guide: 39-Phoneme Classification (Comparable to Paper)

    Paper Baseline

    - Willett et al. report ~61.4% single-trial phoneme classification across 39
    phoneme classes
    - Chance = 1/39 ≈ 2.6%
    - Their method: GRU RNN decoder (trained on full sentence data with temporal
    context)
    - Their 9.1% WER on 50-word vocabulary used a 5-gram language model on top

    Cross-Validation Strategy

    For phonemes, we have 2 sessions (not 20 like diagnostic blocks):
    - Option A: Block-wise CV within each session (use blockNum from the .mat file)
    - Option B: Train on one session, test on other (cross-session generalization,
    harder but more meaningful)
    - Option C: Merge both sessions, do 5-fold stratified CV with block grouping

    Recommend Option B first (cross-session) as it tests generalization, then Option
     A for best absolute numbers.

    Critical Lessons Learned

    1. Dryad is bot-protected (Anubis) — use Zenodo mirror for programmatic
    downloads
    2. Data is pre-processed spike power, not raw ECoG — no need for
    notch/bandpass/Hilbert
    3. Z-score per block is essential — neural features drift across blocks
    4. 1280 features (spikePow×256 + tx1-4×256) works well — don't reduce channels
    5. AMP + DataParallel across 4 H100s gives great throughput
    6. Early stopping at patience=25-30 prevents overfitting on small datasets
    7. TCN converges fastest and gives best results; GRU is most comparable to paper
